# Gaurav Kumar Portfolio

A modern personal portfolio website built with React and Vite, designed to showcase professional skills, projects, education, and contact information in a polished developer presentation.


---

## 🔗 Live Demo

**[gauravk.vercel.app](https://gauravk.vercel.app)**

---




## Overview

This portfolio project features:
- A responsive multi-section layout with smooth scroll navigation
- Hero section with animated typing effect and interactive profile styling
- Projects gallery with modal details, live demo, and source code links
- Contact form integration using EmailJS for direct messaging
- Modern glassmorphism styling powered by Tailwind CSS and custom gradients

## Key Features

- Responsive design for mobile, tablet, and desktop screens
- Sticky navigation with active section highlighting
- Animated typing effect to highlight professional roles
- Project cards with dynamic modal details and tagged tech stacks
- Contact form with toast notiﬁcations for success and error states
- Resume download link for quick access to professional credentials

## Technology Stack

- React 19
- Vite
- Tailwind CSS
- EmailJS
- React Icons
- React Simple Typewriter
- React Parallax Tilt
- React Toastify
- ESLint

## Project Structure

- `src/App.jsx` — Page layout and section composition
- `src/components/` — Modular portfolio sections (About, Skills, Work, Education, Contact, Footer)
- `src/constants.js` — Shared project data and assets
- `src/index.css` — Global styling and Tailwind configuration

## Getting Started

### Prerequisites

- Node.js v18+ recommended
- npm installed

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the local server URL shown in the terminal to preview the portfolio during development.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Customization

To personalize the portfolio for your own profile:
- Update the `About` section text and typing roles
- Replace project entries in `src/constants.js`
- Change the profile image and resume link
- Adjust contact form settings or EmailJS configuration

## Notes

This portfolio is built as a static frontend application with a focus on visual presentation, navigation clarity, and a professional developer showcase. It can be deployed on platforms like Vercel, Netlify, or GitHub Pages.
